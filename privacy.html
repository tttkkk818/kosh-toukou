Privacy Policy — Kosh Toukou

Last updated: October 26, 2026

Kosh Toukou ("the tool") is a private tool used only by its owner to upload and schedule videos on the owner's own YouTube channels. The tool uses YouTube API Services. By using the tool, the user is agreeing to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Information the tool accesses

  • Basic information about the authorized YouTube channel (channel ID and channel title), used to confirm which channel a video is uploaded to.
  • Upload status and publishing settings of videos the tool uploaded (for example privacy status and scheduled publish time), used to confirm the upload succeeded.

The tool does not access comments, subscribers, analytics, or any data of other users.

How the information is stored and used

  • OAuth tokens are stored only on the owner's own computer, in a folder that only the owner can read. They are never sent to any server other than Google's.
  • A simple log of uploads (date, channel title, video ID and status) is kept by the owner for their own records.
  • Information is used only to upload and schedule the owner's videos. It is not sold, shared with third parties, used for advertising, or used to train AI models.
  • The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Cookies and device information

The tool has no website features for end users and does not store, access, or collect cookies or device information.

Revoking access and deleting data

Access can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions. When access is revoked, the stored tokens stop working and are deleted from the owner's computer. Upload logs can be deleted by the owner at any time.
