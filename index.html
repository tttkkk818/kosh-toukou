Kosh Toukou

Kosh Toukou is a private, internal tool used only by its owner to upload and schedule videos on the owner's own YouTube channels. It runs on the owner's computer and uses the YouTube Data API (YouTube API Services). It is not offered to the public, and no other users can sign in to it.

What it does

  • Uploads video files that the owner has prepared to the owner's own YouTube channels.
  • Sets the title, description, tags, thumbnail, playlist and scheduled publish time chosen by the owner.
  • Reads back the upload status so the owner can confirm the video was scheduled correctly.

By using this tool, the user agrees to be bound by the YouTube Terms of Service.
